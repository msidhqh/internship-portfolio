# Personal Portfolio

Editorial portfolio for an Information Technology student seeking internships.

## Fill in before sharing

Edit `src/content/profile.ts`:

- `[YOUR NAME]`
- `[YN]` (monogram)
- `[ADD EMAIL]`
- `[ADD LINKEDIN URL]`
- `[ADD GITHUB URL]`
- `[ADD PORTFOLIO URL]`
- `[HACKATHON NAME]`
- `[HACKATHON DATE]`
- `[SIT CLUB DATES]`

Also update the same name and URLs in `index.html` (title, meta, Open Graph).

Project write-ups live in `src/content/projects.ts`. Add GitHub or live demo URLs only when they exist. Replace the decorative previews with screenshots when you have them (`[ADD PROJECT SCREENSHOT]`).
